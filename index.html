How it works

Measure

A heat probe and a door counter report temperature and visitors. No cameras.

Plan

SteamFox Cloud reads tomorrow's prices and expected visitors, and plans the cheapest way to be hot on time.

Act

Owners get alerts and one-tap advice, or let Autopilot run it. Bathers check the live map.
